# 🪝Hook

Hook intends to be an all-in-one alternative to the standard *Arr stack (sonarr, radarr, seerr, prowlarr, VPN, and torrent client). The aim is to use a much smaller memory and CPU footprint whilst also being simpler to set up.

I'm building this app to meet my personal use case (low-power server, torrents instead of usenet, Wireguard VPN usage).
